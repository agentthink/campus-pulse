在未实际核验前，不会把 C02 资产写成“已复用”。

### 3. ML 任务与验收细节

虽然已确认按最高标准实施，仍需要明确：

- 任务：未来 30 分钟风险分类？异常检测？还是回归预测？
- 标签定义、预测时间窗与各区域样本规模。
- 是否指定模型族、离线 / 在线推理位置或算力约束。
- 教师期望的 Rule 基线、评估指标与最低阈值。
- 数据来源是否允许模拟数据为主，以及公开数据如何获取与引用。

### 4. 外部 API、RAG 与工具

- 天气 / 空气质量服务使用哪个 API？是否需要 API Key，由谁提供？
- RAG 是否必须使用真实检索服务，还是允许 SQLite FTS / 本地向量索引作为知识检索实现？
- 知识库来源与版本由谁提供？是否允许项目自建演示知识库？
- 固定证据快照的采集与验收方式。
- Tool Calling 是否必须接入外部真实工具，还是系统内部工具也可验收。

### 5. ASR 验收

- 支持哪些语音指令：切换区域、查询状态、记录 Action，还是仅有限界面操作？
- 语言、麦克风权限与失败处理要求。
- 是否允许浏览器 Web Speech API，还是必须使用指定 ASR 服务？
- 若现场环境噪声较大，验收如何模拟？

### 6. H5 / Camera / TTS

- Camera 是否要求照片上传到后端并持久化？照片与 event 的关联规则。
- TTS 使用浏览器语音还是指定语音服务；是否需要中文音色与限制说明播报。
- H5 是否必须支持内联记录 Action，还是当前只读预览 + Web 处置即可？
- 地图是否接受 2.5D 示意，不要求真实 3D / GIS 坐标准确性。
